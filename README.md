## Сетка и позиционирование

В проекте реализованы:

- CSS Grid для сетки карточек товаров (адаптивная, `auto-fit` + `minmax`);
- Flexbox для навигации в шапке;
- Grid для шапки сайта (логотип + меню);
- `position: sticky` для шапки;
- `position: absolute` для бейджей «Новинка» и «Скидка»;
- `position: fixed` для кнопки «Наверх»;
- `z-index` для шапки, бейджей, кнопки «Наверх» и модального окна.

## Использование Flexbox и Grid

- Flexbox — для основного меню;
- Flexbox — для внутренней структуры карточек товаров;
- CSS Grid — для сетки карточек;
- CSS Grid — для страницы каталога с фильтрами и списком товаров.
